# 工事実績管理AI 統一モック
以前の公開画面を基準に、既存の案件・実績検索・技術者・期限・ナレッジの画面を残し、月/週/日カレンダー、案件別OCRデモ、階層フォルダを統合しています。
旧版の資料チェック・期限・判定は固定の表示例です。AIや業務データへの接続はありません。数値を予測精度とみなさないでください。

## 操作
案件のカレンダーで「20件のデモ日」を選び、日付から日表示へ進めます。同時刻の案件を個別に選択できます。
案件詳細→入札資料を追加→固定サンプル→抽出案の確認・修正→登録。実ファイルを選択・送信しません。
工事別フォルダでは案件内に子フォルダを作成・改名・移動できます。PDF/Excel/Wordは架空メタデータのみ。循環移動と案件間の移動は禁止します。
データはこのブラウザのlocalStorageのみ。リセット可能です。以前の別モックの保存データは変更・移行しません。

## 運用前に必要な実装
実AI OCR、PDF/画像の出典ページ、曖昧項目のレビュー、ファイル保管・ダウンロード・版管理は未実装です。
認証・テナント/フォルダのアクセス制御・暗号化・IP制限・2要素認証は機密情報投入前に実装と検証が必要です。本番構成は未決定。実資格情報を入力しないでください。
