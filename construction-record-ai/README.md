# 工事実績管理AI 操作モック
架空データ専用・既存本体とは未統合です。機密情報は入力しないでください。
月・週・日カレンダー、1日20件、時間帯別、時刻未定、詳細と追記履歴を操作できます。
案件詳細の「入札資料を追加」から固定サンプル→AI OCR抽出案→原文1ページとの照合・修正→案件への確認登録を試せます。AI OCRはデモ・実解析なし。
工事フォルダは案件別の階層、パンくず、子フォルダ作成、名前変更、移動に対応。PDF・Excel・Wordは架空のメタデータのみ。実ファイル選択・保管・外部送信はありません。移動は同じ案件内のみで循環を防止します。
入力はこのブラウザのlocalStorageだけに保存します。実ストレージやGoogle Driveとは未連携。リセットで初期データへ戻せます。
認証・暗号化・IP制限・2要素認証は未実装。実際の機密情報投入前に実装と検証が必要です。実AI予測・OCR・ファイルダウンロード・版管理は未実装です。
CSSとJSは相対パス参照。外部API・CDNを使用しません。
